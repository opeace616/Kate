# 日日有力｜健身手帳

奶茶與淡粉風格的繁體中文健身紀錄工具。

- 重訓：日期、動作、重量、kg/lb、次數、組數、備註與上次重量
- 固定菜單儲存與帶入
- 有氧：坡度、速度、時間
- 晨重、體脂率與趨勢曲線
- JSON 完整備份與還原

## 網站發布

此專案是無需編譯的靜態網站，入口為根目錄 index.html。可由支援靜態網頁的託管服務發布。

GitHub Pages：在 Settings → Pages 選擇 Deploy from a branch，再選擇 main / (root)。私人儲存庫能否使用 Pages 取決於 GitHub 方案；一般 Pages 網站為公開可瀏覽，啟用前請確認可見性。

## 資料儲存

資料只儲存在使用者目前瀏覽器的 localStorage，不會上傳 GitHub。不含雲端同步；換裝置或瀏覽器時，請透過匯出與還原移轉資料。
